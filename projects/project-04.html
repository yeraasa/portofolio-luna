VOYAGELIB

DESCRIPTION arrow_forward


VoyageLib is a digital library website designed to make it easy for users to search for, view, and access information about various book collections. The site features a simple, structured layout with search and collection management tools, enabling users to locate the books they need more easily. Regarding user experience, the design incorporates clear navigation flows to ensure the process of finding information is fast, convenient, and intuitive.
