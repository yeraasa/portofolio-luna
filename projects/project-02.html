DESCRIPTION arrow_forward


Mood Tracker is a simple web application that allows users to record their daily mood by choosing from different emotional states, such as Happy, Neutral, Sad, and Angry. It also provides a weekly overview to help users monitor and reflect on their mood patterns over time.


TECH


Laravel | Tailwind CSS | PHP |Mysql
